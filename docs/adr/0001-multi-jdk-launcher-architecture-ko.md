# ADR-0001: 다중 JDK 및 워크스페이스 격리 아키텍처

- 상태: 채택됨 (Accepted)
- 날짜: 2026-08-28

## 배경 (Context)
전자정부 표준프레임워크 개발자는 레거시(JDK 8 / eGov 3.x)와 모던(JDK 17+ / eGov 4.x) 환경을 전역 환경 변수 오염 없이 스위칭할 수 있어야 합니다.

## 결정 (Decision)
프로세스 레벨에서 환경 변수를 격리하여 동적으로 JDK 런타임과 IDE를 실행하는 독립형 Go 런처 아키텍처를 채택합니다.

## 결과 (Consequences)
- 전역 JAVA_HOME 오염 없이 안전한 로컬 워크스페이스 상태 유지
- 결정론적 프로세스 수명 주기 관리를 통한 다중 버전 공존 가능
