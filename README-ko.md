# egovframe-launcher

[English](README.md) | 한국어

전자정부 표준프레임워크(eGovFrame) 개발 환경 및 다중 JDK/서버 환경 구성을 지원하는 경량 런처 및 개발자 도구입니다.

## 주요 기능

- **다중 eGovFrame 버전 및 JDK 스위칭:** eGovFrame 3.x, 4.x 및 JDK 8/11/17/21 환경 전환
- **로컬 런타임 제어:** 내장 경량 웹 서버 및 콘솔 기반 제어
- **표준 디렉토리 구조 자동 구성:** 워크스페이스 및 서버 템플릿 프로비저닝

## 빠른 시작

```bash
# Go 빌드 및 실행
cd launcher
go run main.go
```
